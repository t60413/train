比價小幫手：伺服器設定

步驟 1　先按這裡複製伺服器程式

步驟 2　建立 Cloudflare 伺服器
  1. 用 Safari 打開 dash.cloudflare.com，用 Email 免費註冊並登入
  2. 找到 Workers 和 Pages（在左上角選單 ☰ 裡），按 建立
  3. 選 從 Hello World 開始（或「建立 Worker」），名稱打 bijia，按 部署
  4. 按 編輯程式碼，把裡面的程式全部刪掉，長按貼上剛剛複製的程式
  5. 按右上角 部署
  6. 複製它顯示的網址，像 https://bijia.你的名字.workers.dev
步驟 3　連上 App
  1. 打開 比價小幫手 → 底下「工具」
  2. 貼上網址 → 按 儲存並測試，看到「連線成功」就完成了
選用：開啟拍照辨識
  1. 到 console.anthropic.com 申請 API 金鑰（要儲值，每張照片約幾毛錢）
  2. 回到 Cloudflare 的 bijia → 設定 → 變數和密碼 → 新增
  3. 類型選 密碼，名稱打 ANTHROPIC_KEY，值貼上金鑰 → 部署
